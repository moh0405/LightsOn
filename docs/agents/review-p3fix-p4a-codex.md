## Findings, most severe first

1. **P1 — Failed or missing detection becomes invented negative evidence.** `scripts/fetch_vexcel.py:108` initializes every requested label to count zero and retains that value when the adapter returns its error fallback; `scripts/fetch_vexcel.py:129` writes those zeros into fixtures. `scripts/build_dossier.py:94` substitutes `recent` for an unknown date, and `scripts/build_dossier.py:100` creates citable facts saying “no … detected” from every zero. Reproduced with a completely offline adapter: fixture contains `car=0`, `tree=0`, capture date null despite no successful observation. This violates AGENTS rules 1/4 and the requested treatment of negative detections; even the committed successful-response zero detections remain in the citable facts list. Preserve success/failure separately, leave unknown counts/dates null, retain negative results as diagnostic metadata rather than citable building facts, and add an end-to-end fetch-to-merge failure regression test.

2. **P2 — Detection cache ignores labels and other request inputs.** `server/app/data/vexcel.py:331` through `:336` uses `detect.json` per property, or a geometry-only hash without a property ID. Calling `detect(..., labels=['car'])` then `detect(..., labels=['tree'])` returns the car response twice with only one network call; reproduced with MockTransport. A later prep scout asking a different question silently gets unrelated evidence, contrary to the real-data/tool contract. Key detection caches by normalized geometry, labels, model/threshold/buffer and relevant collection; property-ID cache namespaces must also distinguish changed geometry.

3. **P2 — Transient and partial oblique failures become permanent cached results.** `server/app/data/vexcel.py:259` treats `_send() == None` (timeout, missing key, transport failure) like a confirmed 404 and writes an empty collection cache, which `:239` accepts forever. Separately, `:245` returns any nonempty set of cached images without checking all advertised directions. Reproduced: two calls after a collection timeout perform just one network attempt; a first run with north success and three HTTP 500 responses is cached as north-only, and the second run performs zero calls to recover missing images. Cache only confirmed no-coverage responses; distinguish transient errors and retry missing directions against the cached collection metadata.

4. **P2 — Typed fallbacks do not cover cache or malformed-response failures.** `server/app/data/vexcel.py:79` creates directories outside a fallback boundary, and `:282` indexes collection properties/date outside the parsing try block. Reproduced `NotADirectoryError` when the cache root is a file, and `KeyError` for successful JSON `{'features':[{}]}`. These escape the adapter into callers despite the explicit Phase 4A “every failure logged and returned as a typed fallback” requirement and AGENTS rule 9. Validate response/cache shape and input geometry, catch operational cache errors, and preserve usable network responses when persistence fails; add malformed-200 and cache-unavailable tests.

5. **P2 — Property IDs can traverse outside the Vexcel cache.** `server/app/data/vexcel.py:73` through `:79` appends arbitrary property IDs to a filesystem path without validation or containment. Reproduced `property_id='../escaped'` writing `property.json` outside the configured cache; absolute IDs also bypass the root. The functions are exported as prep-agent tool aliases at `:418`, so this must be guarded before model-supplied arguments reach them. Match the decimal-ID validation already used by `server/app/data/matterport.py:33` and the data providers, and enforce resolved-path containment before reads or writes. This violates the review's path-traversal requirement.

6. **P2 — Projector fit was achieved by reducing required body text below 28px.** `apps/web/src/screen/ScreenApp.tsx:52` uses 22px player names; `apps/web/src/screen/overlays/RoundOverlays.tsx:55` uses a 22px simulation label and `:60` uses 24px city-need labels. PRD “Overlays” explicitly requires body text >=28px at 1080p, and the Phase 3 fix spec repeats it. Both real-QR layout tests pass, but neither checks computed font sizes. Preserve the 28px minimum for these body labels while adjusting spacing/layout; add the font-size check to the existing layout test.

7. **P2 — New fact-merge tests do not run the merge implementation.** `server/tests/test_vexcel.py:115` and `:131` read already-generated dossier artifacts rather than calling `scripts/build_dossier.py`. Removing the new Vexcel merge code would leave these checks green while committed fixtures remain unchanged. The suite has no successful HTTP oblique-sequencing test and no changed-label/cache-recovery coverage, which allowed findings 1–3 through.
